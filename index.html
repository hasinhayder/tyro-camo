ZERO-FRICTION INTEGRATION

ADD ONE LINE
TO VITE.CONFIG.JS

Zero changes to your Blade files, build files, or Rollup pipeline. Just register the plugin and everything else is handled automatically behind the scenes.

vite.config.js 
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';
import { tyroCamo } from 'vite-plugin-tyro-camo';

export default defineConfig({
  plugins: [
    laravel({
      input: ['resources/css/app.css', 'resources/js/app.js'],
      refresh: true,
    }),
        tyroCamo(), // <-- Zero Blade changes. Zero build tweaks.
  ],
});
FULLY AUTOMATED Zero Blade edits, no Rollup overrides, no manual manifest patching. Your build commands (npm run build) run identically as before.
TOTAL CONTROL

CHOOSE YOUR
FILE NAMING STRATEGY

Want fixed aliases for key scripts, or prefer silent cryptographic hashes for everything else? Configure how unmapped assets are named with unmappedStrategy.

'codename' Default

Generates pronounceable, innocuous adjective-noun pairs from built-in or custom dictionaries.

Output example: assets/swift-tiger-C9x0a.js
'nameless' Silent

Strips all descriptive identifiers and codenames, leaving only pure content hashes.

Output example: assets/C9x0a4f8.js 
// Customize how non-aliased assets are emitted:
tyroCamo({
  // Options: 'codename' | 'nameless'
  unmappedStrategy: 'codename',
  format: 'assets/[codename]-[hash][extname]',
})
